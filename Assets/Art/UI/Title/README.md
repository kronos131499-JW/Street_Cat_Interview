# Title art

Authoring copies of the files in `Assets/Resources/VnArt/Title/`.

| Folder | Contents |
|---|---|
| `MenuButtons/` | Main-menu buttons (`*_normal` / `*_selected`) |
| `Desk/` | Title desk, magazine, logos, and props |
| `Shared/` | Tape buttons and paperclip used by notebook, writing, and interview |

Edit the file here, then copy the same png into the matching `Resources/VnArt/Title/` folder so the game picks it up.
