## 素材异常与未直接使用项

- 自由采访/目录框（选中）.png 尺寸为 1920×1080，而未选中图为 244×79，疑似导出画布异常；已按保持比例方式加载，建议重新裁切导出。
- 对话界面/打字框的字.png 是固定中文提示。游戏输入提示支持语言切换，因此仍使用动态文字，避免英文模式显示中文烘焙字。
- 写稿素材卡库/标题.png 是 1920×1080 画布，界面标题仍需支持本地化动态文字；该图已导入但未覆盖动态标题。
- 写稿素材卡库/已选素材.png 是固定中文，计数会实时变化，因此保留动态计数文字。
- 写稿素材卡库/预览按键.png 已导入，但当前游戏流程关闭了独立预览入口，玩家直接进入可编辑成稿界面。
- 成稿界面/预览图标已导入，但当前成稿流程没有独立预览按钮。
- 对话界面/记者笔记.png 已导入；常规对话当前通过菜单进入笔记，没有固定独立按钮位置。
- 主菜单素材中的“章节”和“成就”已导入，但当前游戏没有对应功能，未绑定到其他功能。
